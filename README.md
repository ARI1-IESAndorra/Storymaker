# La Asombrosa Máquina de Generar Historias

Este repositorio recopila y organiza todos los recursos técnicos necesarios para replicar, adaptar y mejorar **La Asombrosa Máquina de Generar Historias**, un dispositivo físico interactivo destinado al fomento de la lectura infantil y juvenil, basado íntegramente en **hardware y software libre**.

El objetivo es claro: transformar un artefacto creativo en un sistema **documentado, reproducible y accesible**, apto para su construcción en centros educativos, bibliotecas, espacios culturales o makerspaces, sin dependencia de soluciones propietarias.

Aquí no hay magia. Hay electrónica, código, mecánica y documentación bien explicada.

---

## ¿Qué es este proyecto?

La máquina es un dispositivo interactivo que propone historias de forma aleatoria o semialeatoria, combinando elementos narrativos mediante una interfaz física pensada para su uso por niños y jóvenes.

Este repositorio no define un producto cerrado, sino una **base técnica común** desde la que se puede:

- Replicar el dispositivo tal y como se plantea.
- Adaptarlo a distintos contextos educativos o culturales.
- Modificar su diseño físico o electrónico.
- Ampliar y mejorar sus funcionalidades.

---

## ¿Qué encontrarás en este repositorio?

El contenido está organizado por áreas técnicas, siguiendo una lógica de proyecto industrial y educativo:

- Esquemas electrónicos y documentación de hardware.
- Código fuente del firmware y del software de control.
- Modelos 3D y planos mecánicos listos para fabricación digital.
- Archivos CAD y recursos gráficos asociados al diseño.
- Manuales técnicos de montaje, puesta en marcha y mantenimiento.
- Propuestas de versiones y variantes del dispositivo, con sus diferencias documentadas.

Todo el material se publica bajo **licencias abiertas**, permitiendo su uso, estudio, modificación y redistribución.

---

## ¿A quién va dirigido?

Este repositorio está pensado para perfiles diversos:

- Docentes de Formación Profesional, tecnología o ámbitos STEAM.
- Centros educativos que quieran desarrollar el dispositivo como proyecto.
- Bibliotecas y asociaciones culturales interesadas en el fomento de la lectura.
- Makers y personas con experiencia técnica que quieran profundizar o mejorar el diseño.

No es necesario dominar todas las áreas técnicas. La documentación está planteada de forma **modular**, permitiendo abordar el proyecto por partes.

---

## ¿Qué se consigue al completar el proyecto?

Una vez construido y configurado el dispositivo, se obtiene:

- Una máquina funcional, robusta y reproducible.
- Un recurso educativo y cultural listo para su uso.
- Un ejemplo real de proyecto open source aplicado a la educación y la cultura.
- Una base técnica sólida para futuras mejoras o personalizaciones.

---

## Espíritu del repositorio

Este GitHub no es un escaparate. Es una **caja de herramientas**.

La prioridad es la claridad técnica, la replicabilidad y la mejora continua.  
Si algo se puede explicar mejor, se explica.  
Si algo se puede simplificar, se simplifica.  
Y si algo se puede mejorar, se documenta para que otros lo hagan.

Las contribuciones, sugerencias y adaptaciones son bienvenidas. El conocimiento compartido funciona mejor cuando se construye entre muchos.
